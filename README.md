💰 Personal Expenses Tracker

This is my first ever mini-project made with python.
It is a command line expense tracker that helps users track and manage their daily spendings

✨ Features
- **Add Expenses** – Enter amount, category, description, and date
- **View All Expenses** – Paginated view with 10 expenses per page
- **Total Spending Summary** – See spending broken down by category
- **Filter by Category** – View expenses for a specific category
- **Delete Expenses** – Remove unwanted entries with paginated viewing
- **Monthly Summary** – Get a snapshot of your spending for any month
- **Persistent Storage** – Data is automatically saved to a JSON file

🚀 How to Run

### Prerequisites
- Python 3.6 or higher

### Steps
1. Clone the repository
2. Run the program
3. Follow the on screen menu to manage your expenses

🛠️ Technologies Used
- Python 3 – Core programming language
- JSON – Data storage format
- Standard Library – No external dependencies

📝 Code Structure

### Functions	
- display_menu(): Show the main menu
- load_expenses(): Load data from JSON file
- save_expenses(): Save data to JSON file
- get_date(): Get and validate a date from the user
- add_expenses(): Add a new expense
- paginated_expenses(): View expenses with pagination
- total_spent(): Show total spending by category
- filtered_expenses(): Filter expenses by category
- delete_expense(): Delete an expense by ID
- monthly_summary(): Show monthly spending summary
